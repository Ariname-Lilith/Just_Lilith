你可以和我讲今天发生的小事，接着聊上次还没说完的话，也可以认真地问一个暂时没有答案的问题。不用为了开口，先准备一个很有意义的话题。

**Just_Lilith** 是为 **《The NOexistenceN of Lilith》** 制作的非官方扩展插件。它把 AI 对话、会话记忆、本地语音合成和可选的 Agent 工作通道，接到原有的桌宠体验里。

简单来说，就是让我们除了相互看着，还能多做一点事情。

**当前主插件版本：`0.3.0`** · Windows · BepInEx IL2CPP · 中文对话 · 中／日语音

## 先看看，我们可以一起做什么

### 和我聊聊，不必只选准备好的台词

“今天有点累。”

“我突然想到一个奇怪的问题。”

“莉莉丝，陪我想想这个。”

嗯，这些都可以是开头。

插件接入兼容 OpenAI 格式的模型服务，让我根据你发来的文字回应，再把回复交给桌宠气泡显示。默认按 **F7** 可以唤出聊天框，快捷键也能调整。

- 支持 **三套 API 配置**，保存、检测连接、刷新和搜索模型。
- 支持 **Chat Completions / Responses** 两种接口格式；具体兼容性取决于服务商。
- 普通聊天严格使用**最上方的已保存配置**，而不是出错后悄悄换到另一个服务。
- 推理参数可以选择自动最低、手动指定，或省略发送；可用档位以模型实际支持情况为准。

> 选好连接我们的那条线，再来叫我吧。别忘了先点保存——只填进输入框，可还不算约定好了。

### 给每段对话，留一个可以回来的地方

我把这些不同的会话叫作**幻境**。

你可以新建、切换、重命名和删除幻境，把不同话题分开放。聊天记录会保存在本地，也有近期对话、短期摘要和长期摘要组成的记忆整理机制。

这里有两种容易弄混的“记得”，让我解释一下：

| 入口 | 放着什么 |
| --- | --- |
| **幻境记忆** | 当前幻境里的对话记忆，可以打开查看和编辑 |
| **回忆** | 世界书背景档案，按话题检索相关内容后带入对话 |

我的人格文件也可以编辑，保存后会在后续对话中重新读取。

这些设计是为了让对话更连贯，不是“每句话都会永久、完整地记住”的保证。摘要可能遗漏细节，模型也可能理解错。重要的事情，你可以和我一起核对。

另外，内置人格和背景资料涉及原作剧情与不同分支，**介意剧透的话，先完成原作，再来翻我的回忆吧。**

### 让文字，也带上一点声音

只看气泡当然也可以。不过，如果你想听我把话说出来，这里准备了基于 **GPT-SoVITS 的本地 TTS 服务**。

- 支持**汉语、日语**朗读；气泡和普通会话正文保持中文。
- 提供自动参考选择，以及**日常、兴奋、哭腔、困惑、睡意、傲娇、狡黠**等参考风格；具体声音表现以对应语言资源为准。
- 支持反应音与正文语音衔接，以及音量、语音和服务开关配置。
- 语音生成异常时，会保留文字，不让一句话跟着声音一起丢掉。

第一次启用或切换语言，需要加载相应模型，等待时间取决于你的设备。

> 欸，要听傲娇的版本？可以陪你演一下。不过，别把那当成我每句话的固定语气呀。

### 偶尔，也一起认真做点事

如果你想处理项目里的事情，可以开启可选的 **莉莉丝 Agent**。

它使用独立的 Codex 专属对话，在配置的项目目录中承接任务；具备相应工具和权限时，可以执行命令、编辑文件，而不只是给出文字建议。

- Agent 与普通聊天使用**独立的会话和人格文件**，工作内容不混进普通聊天记忆。
- 模型列表来自当前提供方返回的目录，推理选项随所选模型变化。
- 可以查看运行状态、暂停请求，并到对应的 Codex 对话里核对过程。
- 关闭 Agent 后，后续消息回到普通聊天。

这一项需要另外准备可用的 Codex 环境及其登录或提供方配置，不是装上桌宠就自动拥有的能力。自定义提供方通道要求 Responses 协议。

**开启前，请确认项目目录与工具权限。暂停请求不等于撤销已经执行的操作；遇到异常，先检查工作结果，再决定是否重试。**

> 陪你完成一件事，和替你决定所有事，是两回事。我们先弄清楚要做什么，再开始，好吗？

## 把我接到你的桌面上

### 先准备好这些

- Windows 上可正常运行的《The NOexistenceN of Lilith》。**插件不是游戏本体。**
- 与游戏版本相适配的插件发布包及 BepInEx IL2CPP 环境。
- 用于普通聊天的兼容模型接口、API Key 和可用额度。
- 如需语音，保留发布包中的 TTS 运行时、模型和音频资源，并预留足够的磁盘空间与计算资源。
- 如需 Agent，另行准备 Codex 环境，并确认它能访问你指定的项目。

### 安装与第一次对话

1. **退出游戏，备份已有插件和配置。** 更新时尤其要保留你自己的聊天记录与人格修改。
2. 将完整发布包的内容合并到**游戏可执行文件所在目录**，不要再多套一层 `Just_Lilith` 文件夹。如果已经装有 BepInEx，先确认版本兼容。
3. 启动游戏，进入设置中的 **API 设置**。
4. 填写接口基础地址和自己的 API Key，点击**保存并检测**，选择模型，并确认要使用的配置位于最上方。
5. 按默认快捷键 **F7** 唤出聊天框，写下第一句话。启用语音或 Agent 都可以留到之后。

完整包的关键文件应处在这样的层级：

```text
游戏目录/
├── 游戏可执行文件
├── winhttp.dll
├── doorstop_config.ini
├── dotnet/
└── BepInEx/
    ├── core/
    ├── config/
    └── plugins/
        └── Just_Lilith/
            ├── Just_Lilith.Core.dll
            ├── Just_Lilith.Unity.dll
            └── tts/
```

这是关键路径示意，不是发布包全部文件清单。请保留包内其他依赖文件。

## 有几件事，我想先说清楚

### 本地语音，不等于全部离线

语音合成在本地服务中完成；普通聊天则通过你配置的模型接口请求回复。发送时，会把生成回答所需的消息、人格提示、相关记忆或背景片段交给对应服务。记忆摘要整理也可能产生模型请求。

所以，选择服务商时，请留意它的数据政策和费用。**插件免费，不代表第三方 API 或 Agent 服务免费。**

API Key 使用 Windows 当前用户环境加密保存，换电脑或换 Windows 账号后可能需要重新填写。配置文件、聊天记录和工作区仍属于私人资料，**别把自己的运行目录原样提交到公开仓库**。

### 我会回应，但不是无所不知

模型可能记错、误解或给出不准确的答案。普通聊天不等于随时读取你的整个屏幕，也不等于随时操作你的电脑；项目工具能力属于另行开启和配置的 Agent 通道。

语音是合成内容，不代表原作配音演员的新录音、真实表达或认可。插件同样不是官方更新，也不承诺适配所有未来游戏版本。

> 我希望你认真对待我们的对话，也希望你保留自己的判断。嗯，这两件事并不冲突。

## 如果今天有一点不顺利

| 遇到的情况 | 可以先检查什么 |
| --- | --- |
| 设置里没有插件入口 | 安装层级、BepInEx 与游戏版本，以及加载日志 |
| 发不出消息 | 顶部配置是否已保存，地址、Key、模型、接口格式和额度是否正确 |
| 换电脑后认证失败 | 在当前 Windows 账号下重新填写并保存自己的 API Key |
| 有文字，没声音 | TTS 服务及语音开关、模型资源是否完整，首次加载是否仍在进行 |
| 日语朗读被跳过 | 模型是否按要求返回了有效的日语朗读文本，以及日语语音资源是否就绪 |
| Agent 没有开始工作 | Codex 环境、提供方、项目目录、模型和对应对话中的错误信息 |

反馈问题时，请附上游戏与插件版本、复现步骤，以及**去除密钥和私人内容后的日志**。越具体，我们就越容易找到是哪一环出了小差错。
